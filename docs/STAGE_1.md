# HELLSPRESSO — 1단계 구현·검증 보고서

기준일: 2026-11-05, SλVE POINT. 0단계 추천안은 임시값으로 유지했다. 이 산출물은 이동·자원·입력·HUD의 실행판이다. 전투부터 엔딩까지 완성됐다고 주장하지 않는다.

## 실행과 전체 파일

Node 24.22.1에서 `npm ci && npm run build`와 `npm test`를 실행했다. `npm run dev`로 플레이하고 `npm run preview`로 dist를 확인한다. 프로젝트의 파일별 전체 내용은 함께 제공하는 `HELLSPRESSO_Stage_1_Full_Source.md`에 있으며 lockfile도 축약 없이 포함한다.

## 구현

- 프로시저럴 이동 검증 공간과 커터칼 임시 메시, 메인 메뉴·정지·소지품 화면.
- WASD·달리기·F 대시·C/Ctrl 슬라이드·2단 점프, 키 변경과 설정 로컬 유지.
- 고정 timestep과 활성 시간 잔량 보존, 메뉴/정지/인벤토리의 서로 다른 시간 정책.
- HP·CAF·STA·독립 사망 원인·공통 clamp·debug CAF 분당 수지.
- WebGL 시작 실패 표시, 락 거절 시 재개 클릭, 그래픽 연결 상실 시 정지.

0단계 캡슐 제안은 직립 AABB로 변경했다. 정적인 바닥·벽·발판 구성에서 작은 의존성과 순수 로직 검증을 유지하기 위해 직접 sweep 충돌을 구현했다. Rapier 또는 캡슐 좁은 단계 충돌을 구현했다고 표현하지 않는다.

## (b) 미검증 항목

실제 PC 마우스/키보드·실제 Alt+Tab·Korean 글꼴과 장치별 배율·Edge/Firefox/Safari·다른 GPU·일반 PC60FPS·동시 장시간 입력·스토리지 쓰기 불능 실험은 미검증이다. headless 환경에는 한글 글꼴이 없어 한글 시각 배치는 실제 PC에서 확인해야 한다. 전투·추출·회복·제작·신성지대·IndexedDB 진행 저장·Firebase·보스·엔딩·배포는 각 후속 단계에서 검증한다. 버그 없음으로 선언하지 않는다.

## (c) 내가 해야 할 일

현재 Firebase/Render 설정은 필요 없다.

1. Node24 설치 후 `npm ci`, `npm run dev`로 실제 PC에서 실행.
2. 마우스 회전, Shift/F/C/Space 두 번, Ctrl 별칭, 키 변경을 확인.
3. 인벤토리 중 CAF 감소와 ESC 정지, 실제 Alt+Tab 복귀 후 클릭 재개 확인.
4. 4단계에서 Firebase 공개 설정·Google 제공업체·Firestore/Rules 준비.
5. 7단계에서 GitHub와 Render Static Site 연결, 빌드 `npm ci && npm run build`, 게시 `dist`, Firebase 승인 도메인 등록.

이번 단계에서 멈춘다. 다음 지시 전에는2단계를 시작하지 않는다.
